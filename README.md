# E-Commerce SQL Analysis

## Project Overview

This project demonstrates SQL-based analysis of an e-commerce database. The database contains customers, products, orders, and order items. SQL queries are used to retrieve, filter, sort, aggregate, and analyze the data.

The project also demonstrates advanced SQL concepts including joins, subqueries, views, and indexes.

## Objectives

- Create an e-commerce database and tables
- Insert sample customer, product, order, and order-item data
- Retrieve and filter data using SQL
- Sort and group data for analysis
- Perform aggregate calculations
- Use different types of JOIN operations
- Use subqueries for analytical queries
- Create and use SQL views
- Create indexes to improve query performance

## Database Tables

The project contains four main tables:

- **Customers** – Stores customer information such as name and city
- **Products** – Stores product names, categories, and prices
- **Orders** – Stores customer orders and order dates
- **Order_Items** – Stores products included in each order and their quantities

## Analysis Performed

The project includes queries to:

1. Display all products
2. Find products belonging to the Electronics category
3. Sort products by price
4. Count products by category
5. Calculate total product value and average product price
6. Combine customer and order information using INNER JOIN
7. Retrieve customer and order information using LEFT JOIN
8. Demonstrate a RIGHT JOIN equivalent using SQLite
9. Find products priced above the average product price
10. Create and display a customer order view
11. Create and verify an index on the Orders table
